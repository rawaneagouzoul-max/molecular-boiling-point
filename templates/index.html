Comment lire une structure SMILES ?

  • C : Carbone
  • O : Oxygène
  • N : Azote
  • = : Liaison double
  • # : Liaison triple
  • ( ) : Ramification
  • 1, 2... : Fermeture de cycle

Les hydrogènes ne sont généralement pas écrits explicitement dans la formule SMILES. Ils sont ajoutés automatiquement par RDKit pour la visualisation et le comptage des atomes.
